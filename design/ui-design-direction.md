# Caitvi Hub UI 设计方向

> 更新日期：2026-11-10
> 适用范围：Caitvi Hub 全站页面、组件、主题色和交互动效
> 状态：已确认的设计方向，具体色值在实现时从动画截图取样并校正对比度

## 设计目标

Caitvi Hub 是以文字为主的个人站点，包含两部分：个人收藏的 CaitVi 同人文（Favorites，按主题分组并链接回 AO3），以及站主自己写的作品（Writing，部分章节带逐句配音）。它不再是策展目录，没有发现页、筛选、评分信号和阅读书架。作品普遍没有封面，页面应依靠标题、作者、摘要、标签、字数和个人推荐语建立层级，不生成统一假封面，也不把作品包装成等宽卡片墙。

视觉方向以现代文学编辑设计为基础，吸收 Emergence Magazine 的滚动聚焦和状态切换逻辑，并将 Kiramman 宅邸的空间语言用于全站结构。默认主题为浅色，同时支持深色模式。

这套设计需要同时表达三个层次：

- Kiramman 家族提供空间、框架和材质语言。
- Caitlyn 提供冷静、精确的蓝色与蓝紫色交互层。
- Vi 提供情感、行动和关系变化所需的红色层。

Cassandra 的个人服装配色不进入网站主题。诺克萨斯、Ambessa 联盟徽记和指挥官时期的军事视觉也不在参考范围内。

## 颜色层级

颜色按照用途分配，不要求 Caitlyn 蓝和 Vi 红等量出现，也不使用红蓝渐变表达两人关系。

| 设计角色 | 颜色方向 | 主要用途 |
| --- | --- | --- |
| 页面基底 | 象牙白、浅石灰、低饱和冷灰 | 默认浅色背景、阅读区域和大面积留白 |
| 正文结构 | 蓝黑、炭灰、石板灰 | 正文、导航、元数据和基础分隔 |
| Kiramman 主色 | 深瓶绿、孔雀绿、灰绿色 | 家族框架、重要容器、选中区域和深色主题表面 |
| Kiramman 金属色 | 旧金、黄铜 | 纹章细节、编号、角部、窄线和精密结构 |
| Caitlyn 角色色 | 深蓝、蓝紫 | 链接、当前阅读位置、主要操作和键盘焦点 |
| Vi 角色色 | 暖红、玫红 | 情感内容、推荐语、Vi 的配音台词和主动交互反馈 |
| 家族次级色 | 酒红、紫罗兰 | 少量织物感表面、引文和特殊叙事节点 |

绿色与金色是 Kiramman 家族最稳定的组合。宅邸内部墙面、家具织物、Kiramman Key 和 Caitlyn 青少年时期射击比赛佩戴的袖章，都反复使用绿色底色与金色或浅色纹章。酒红和紫罗兰保留为次级颜色，不承担全站主结构。

金色只表现精密金属、镶嵌和家族传承。它适合细线、小面积角部和关键编号，不用于大面积背景、粗边框或高亮文字。

### 浅色模式

浅色模式以纯色的象牙白或浅石灰为主。绿色用于框架和局部表面，蓝色用于主要交互，红色只在情感或主动状态中出现。页面不添加渐变光斑、彩色雾化背景或玻璃层。

### 深色模式

深色模式使用带蓝绿倾向的炭黑或深墨绿，不使用纯黑配霓虹红蓝。正文采用暖灰白，金色降低亮度和面积，Caitlyn 蓝与 Vi 红降低饱和度，避免深色主题变成游戏启动器或军事界面。

## 颜色代表注意与情感连接

Cassandra 葬礼段落中，Vi 是家族成员之外唯一保持清晰色彩的人。网站将这一视觉关系转化为状态逻辑：颜色用于表达当前注意、选择和情感连接，不只是装饰。

滚动列表中的非 active 内容降低饱和度和视觉对比，但仍需满足文字可读性。进入视口中心的内容恢复完整标题颜色，编号和结构显示 Caitlyn 蓝，作者、推荐语或关键元数据可以出现少量 Vi 红。点击后，详情弹窗恢复完整的绿、金、蓝紫和红色层级。关闭弹窗后，颜色重新收束到当前 active 内容。

选中与取消选中必须有清楚的反向过程。颜色变化同时配合字重、位置、下划线、边框或明确文字，不能成为唯一的状态信号。键盘焦点、错误和收藏状态也不能共用同一种红色表达。

## Kiramman 宅邸的全站结构语言

轴线对称、垂直比例、重复几何、精密框架和留白尺度是全站设计原则，不只用于 List 页面。不同页面根据内容用途调整表达强度，List 详情页是其中最完整、最明显的应用。

### 轴线对称

关键入口、当前阅读位置、详情弹窗和重要叙事节点围绕明确的中央轴组织。对称用于建立秩序和家族感，不要求所有内容都居中，也不要求每个页面左右镜像。

发现页和搜索结果可以在稳定框架中保持不对称，让标题长度、摘要和标签形成自然节奏。首页、列表详情和书籍弹窗可以更明显地使用中央轴。

### 垂直比例

宅邸的高窗、立柱和狭长构件转化为页面的纵向节奏。首屏、章节入口和页面转场可以使用较高的垂直空间，正文和列表条目仍保持适合扫描的密度。

垂直比例不能通过无限放大标题或拉开每条作品的距离实现。留白集中在页面边缘、章节开始、章节结束和重要状态切换处。

### 重复几何

重复几何来自宅邸窗格、门框、墙板、钥匙结构和镜像 K 纹章。页面可以提取菱形节点、窄长矩形、斜向切线、阶梯式角部和重复平行线。

这些几何只用于外框、导航轨道、选中状态、弹窗书页和少量分隔。家徽不作为连续背景纹样，也不在每个卡片或按钮上重复。

### 精密框架

框架应表现准确的对齐、稳定比例和克制的金属细节。普通内容优先依靠留白和排版分组，边框只用于真正需要边界的弹窗、输入、选中状态和可交互区域。

同一容器不同时叠加边框、宽阴影、渐变和圆角。金色框架保持窄而清晰，绿色表面保持纯色。

### 留白尺度

留白用于建立空间权力和阅读节奏。大尺度留白出现在页面外缘、首屏、章节边界和详情版心；作品列表内部保持紧凑，避免每篇作品都像独立海报。

移动端不强行保留桌面轴线。中央轴可以退化为左侧编号轨道或顶部进度，正文宽度和触控目标优先。

## 各页面的应用强度

| 页面 | 建筑语言的主要应用 |
| --- | --- |
| 首页 | 垂直首屏、中央入口、克制的左右信息平衡 |
| Favorites 首页（`/lists`） | 编号、个人说明和列表入口形成清晰纵向秩序 |
| List 详情 | 中央阅读轴、两侧信息、滚动聚焦和颜色恢复 |
| 作品详情弹窗 | 双页书籍结构、绿金镶嵌、精密边框和中央书脊 |
| Writing 首页与作品页（`/works`） | 编号行和章节目录，纵向秩序，不使用卡片 |
| 章节阅读页 | 窄正文栏、衬线正文，建筑语言退到页眉和章节导航；底部固定配音播放条 |
| About | 家族档案或编辑前言式版面，使用较强留白和垂直比例 |

## List 页的具体规则

List 页面是 Kiramman 建筑语言最完整的试点，但仍需保持真实列表的扫描效率。

- 桌面端以中央标题和作者为主轴，编号或进度位于左侧，元数据和操作位于右侧。
- 中央不显示贯穿页面的横线，只保留两侧信息和必要的局部几何。
- active 内容与相邻内容通过颜色恢复、字重和轻微尺度变化区分。
- 条目间距保持紧凑，大尺度留白放在列表开始、结束和章节切换位置。
- 点击作品后继续使用双页书籍弹窗，不改成普通居中卡片。
- 弹窗外层可以使用深绿或灰绿，页边使用窄金线，中央书脊保留真实阴影。
- 弹窗按钮使用直角或小圆角，避免胶囊按钮、发光按钮和大面积品牌色填充。
- 关闭弹窗后将焦点返回原作品，并恢复对应的 active 状态。

## 章节阅读与配音的具体规则

章节阅读页以正文为先，配音是附加层，不能打断阅读。

- 有配音的台词以下划线和行首小播放按钮标记，整句可点击；没有配音的章节不出现播放条。
- 说话人用颜色区分：Caitlyn 的台词用 Caitlyn 蓝，Vi 的台词用 Vi 红，其他角色用绿色结构色。颜色之外必须同时有图标变化（播放 / 暂停）和可读的 `aria-label`。
- 正在播放的台词使用同色的浅底高亮；加载、暂停和出错各有独立状态，出错时在播放条里用文字说明。
- 底部播放条只包含上一句、播放 / 暂停、下一句、当前说话人与台词、连续播放开关和细进度线，直角按钮，不使用波形、封面或发光效果。
- 连续播放或用播放条跳句时，目标台词不在可视区域内才滚动到视野中央；reduced motion 下不使用平滑滚动。
- 草稿只在本地开发环境显示，并用文字标注“Draft · local preview only”。

## 动效原则

动效用于表达加载、滚动位置、聚焦、选中、取消选中和详情展开。参考 Emergence 的价值在于状态与阅读位置的关系，不复制无关的鼠标特效或入场表演。

- 首屏固定文字只在内容需要建立纵向叙事时使用。
- 滚动聚焦以颜色、透明度和小幅 transform 完成，避免改变布局尺寸。
- 列表中的每一项不重复执行 fade-up 或 stagger。
- 详情弹窗保留书籍展开感，但动画时间保持短，关闭过程必须清楚。
- 所有动效支持 `prefers-reduced-motion`。

## 不采用的视觉元素

- Cassandra 的个人服装配色。
- 诺克萨斯、Ambessa 联盟徽记和指挥官时期军事配色。
- 红蓝各占一半或红蓝渐变。
- 大面积金色、皇家蓝配亮金和重复家徽。
- 伪封面、抽象插图和统一图标块。
- 背景 blur orb、霓虹 glow、毛玻璃堆叠和宽软阴影。
- 每个区块都使用大标题、宽字距 uppercase 标签和超大留白。
- 仅靠颜色表达 active、selected、focus、error 或 reading status。

## 实现和验收

具体色值由实现负责人从已确认的动画截图中取样，再分别校正浅色与深色模式下的对比度。普通文字对比度不低于 4.5:1，大号文字和关键控件边界不低于 3:1。

每个页面实现后至少检查桌面、移动端、键盘操作、触控操作、浅色模式、深色模式和 reduced motion。List 页面还需要验证滚动 active、点击 selected、关闭 deselected、焦点返回和书籍弹窗内部滚动。章节阅读页还需要验证单句播放、暂停、上一句 / 下一句、连续播放、音频加载失败，以及无配音章节不显示播放条。
